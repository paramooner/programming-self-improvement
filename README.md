# 编程手的自我修养 —— 数模作图空间

目标：**快速做出可以冲击数模国赛的优秀图**。
本空间的定位：一份全队规范 + 一套可复用模板库 + 个人学习笔记（精华沉淀）。

## 目录导航

```
├── 数学建模作图规范.md     # 【先看】全队约定：字号/分辨率/配色/命名/图题/检查清单
├── 模板库/                 # 【主力】赛时直接调用的出图模板（见 模板库/README.md）
│   ├── theme.py            #   公共底座：统一色板 + 主题切换 + 保存工具
│   ├── 折线图.py           #   一种图 = 一个文件，自带演示数据可独立运行
│   ├── 折线图.pdf/.png     #   运行后生成的图，与代码放一起
│   ├── 对数折线图.py
│   ├── 对数折线图.pdf/.png
│   ├── 灵敏度分析图.py
│   ├── 灵敏度分析图.pdf/.png
│   ├── 森林图.py
│   ├── 森林图.pdf/.png
│   ├── journal.mplstyle / minimal.mplstyle  # 两套主题
│   └── 素材/               #   参考样图（每种图对应一张，图文件 docstring 有标注）
├── 学习笔记/               # 个人精华笔记（prompt + 完整代码，可独立复刻参考）
└── 物理演示图.pptx         # 演示用 PPT
```

## 使用路径

1. 读《数学建模作图规范.md》——知道"什么算合格的图"
2. 用 模板库/ ——赛时 90% 的图从对应图文件生成，只改数据和标题
3. 需要新图类型时——复制一个图文件作模板，新建对应文件（见 模板库/README.md）
4. 想精读某类图的完整实现——翻 学习笔记/ 对应篇目
