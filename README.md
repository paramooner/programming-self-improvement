# 编程手的自我修养 —— 数模作图空间

目标：**快速做出可以冲击数模国赛的优秀图**。
本空间的定位：一份全队规范 + 一套可复用模板库 + 个人学习笔记（精华沉淀）。

## 目录导航

```
├── 数学建模作图规范.md     # 【先看】全队约定：字号/分辨率/配色/命名/图题/检查清单
├── 模板库/                 # 【主力】一张图 = 一个代码 + 参考图（见 模板库/README.md）
│   ├── 基本折线图.py + 参考_折线图.png
│   ├── 对数坐标折线图.py + 参考_对数折线图.png
│   ├── 局部放大图.py + 参考_灵敏度分析图.png
│   ├── 森林图.py + 参考_森林图.png
│   ├── data.csv             # 示例数据（折线图代码用，可替换）
├── 学习笔记/               # 个人精华笔记（prompt + 完整代码，可独立复刻参考）
└── 物理演示图.pptx         # 演示用 PPT
```

## 使用路径

1. 读《数学建模作图规范.md》——知道"什么算合格的图"
2. 用 模板库/ ——赛时 90% 的图从对应图文件生成，只改数据和标题
3. 需要新图类型时——复制一个图文件作模板，新建对应文件（见 模板库/README.md）
4. 想精读某类图的完整实现——翻 学习笔记/ 对应篇目
