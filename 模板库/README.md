# 数模作图模板库

**一种图 = 一个文件**。每个图文件自带演示数据、可直接运行，赛时打开对应文件改数据和标题即可出图。
配套规范见《数学建模作图规范.md》（字号/分辨率/配色/命名/图题的全队约定）。

## 文件结构

```
模板库/
├── theme.py            # 公共底座：统一色板 + 字体 + 主题切换 + 保存工具（所有图共用）
├── journal.mplstyle    # 主题A：期刊风（刻度向内、双轴虚线网格）—— 结果图、灵敏度图
├── minimal.mplstyle    # 主题B：极简风（隐藏上右边框、仅水平网格）—— 数据探索、时序图
├── 折线图.py           # 单折线 + 关键节点标注 + 区间阴影
├── 折线图.pdf/.png     # ← 运行折线图.py 生成的图，与代码放在一起
├── 对数折线图.py       # 多系列折线 + 对数坐标 + 垂直阴影区间
├── 对数折线图.pdf/.png
├── 灵敏度分析图.py     # 样条平滑 + 局部放大 inset + 参数区间阴影（国奖高频）
├── 灵敏度分析图.pdf/.png
├── 森林图.py           # 回归 OR / 效应量的学术三线表森林图
├── 森林图.pdf/.png
└── 素材/               # 参考样图：每种图对应一张（图文件 docstring 标注了对应关系）
```

**一张图 = 一个代码 = 一张图**：每个图文件运行后，同名 PDF（排版用）+ PNG（300dpi 预览用）直接生成在代码旁边。

## 怎么用（赛时）

```bash
# 直接运行出图（演示数据 → 同名 PDF+PNG 出现在代码旁边）
python 折线图.py

# 换成你的数据：打开文件，只改「① 数据区」和「② 图形设置区」
```

每个图文件内部结构固定为：
- **① 数据区**：替换成你的数据
- **② 图形设置区**：标题、坐标轴、标注点、填充区间、放大区域
- 运行后输出**与代码同名**的 `.pdf`（排版用）+ `.png`（300dpi 预览用），就在代码旁边
- 函数本身独立可复用（接收 `ax`，方便拼 (a)(b)(c) 子图）

## 图文件速查

| 文件 | 适用场景 | 主要参数 |
|---|---|---|
| 折线图.py | 时间序列主图（GDP、人口、指标趋势） | `annotate=(i0,i1)` 标注节点、`fill=(i0,i1)` 区间阴影、`y_fmt` 数值单位 |
| 对数折线图.py | 数值跨度大的多指标时序 | `log_y` 对数开关、`shade=(x0,x1)` 垂直阴影、`labels` |
| 灵敏度分析图.py | 敏感性分析、多方案对比 | `y_dict` 参数字典、`baseline` 基准线、`zoom=(x0,x1,y0,y1)` 放大区域 |
| 森林图.py | Logit 回归结果、多变量效应对比 | `ors/ci_low/ci_high/p_vals`、`ref` 无效假设值、`x_ticks` |

## 通用约定（已写入 theme.py）

- 颜色：统一 Okabe-Ito 色板（蓝→橙→绿→红→紫→天蓝→黄→灰），按顺序取用
- 字体：SimHei + Times New Roman，负号正常
- 输出：`save_fig` 自动存 PDF（矢量，排版用）+ PNG 300dpi（预览用）到 `figures/`
- 网格：随主题自动（journal 双轴虚线 / minimal 仅水平线）

## 加新图类型

1. 复制任意一个图文件作为新文件（如 `箱线图.py`）
2. 改函数名和绘图逻辑，**只用 `theme.get_color(i)` 取色、`theme.save_fig` 保存**
3. 保留「① 数据区 / ② 图形设置区」的演示结构，直接运行验证
4. 在本文档速查表补一行
