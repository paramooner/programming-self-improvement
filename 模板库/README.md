# 数模作图模板库

**一张图 = 一个代码**：代码提取自学习笔记（完整实现、自包含可运行），图与代码**同名同目录**放在一起。

## 文件结构

```
模板库/
├── 基本折线图.py / 基本折线图.png     # 代码与图同名，放在一起
├── 对数坐标折线图.py / 对数坐标折线图.png
├── 局部放大图.py / 局部放大图.png
├── 森林图.py / 森林图.png
├── 局部放大图_输出.png     # 运行 局部放大图.py 实际生成的图
├── 森林图_输出.png         # 运行 森林图.py 实际生成的图
├── data.csv               # 示例数据（供 基本折线图.py / 对数坐标折线图.py 读取，可替换）
├── image-1.png            # 旧素材（暂无对应代码）
└── README.md
```

## 怎么用

```bash
python 基本折线图.py       # 读取 data.csv 画图（对数坐标多系列折线）
python 对数坐标折线图.py   # 同上（两篇笔记代码相同）
python 局部放大图.py       # 自含模拟数据，生成 局部放大图_输出.png
python 森林图.py           # 自含回归数据，生成 森林图_输出.png
```

- 每个代码文件都是**完整独立脚本**，改数据和样式直接编辑文件即可
- 同名 `.png` 是该图的目标效果（参考），运行代码生成的 `_输出.png` 是实际产出，两者可对照

## 加新图类型

1. 复制任意一个 .py 作新文件（如 `热力图.py`），改绘图逻辑
2. 在 学习笔记/ 里写一篇对应笔记（prompt + 代码），代码放模板库、图放旁边
3. 在本文档表格补一行
